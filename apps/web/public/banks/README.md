# Logos de bancos

SVGs locais para eliminar dependências externas em tempo de renderização.

Nubank, PicPay e Mercado Pago: [Simple Icons](https://github.com/simple-icons/simple-icons), licença CC0. Ícones monocromáticos com fundo da marca.

Demais bancos: [react-bancos](https://github.com/henriquezolini/react-bancos), licença MIT preservada em LICENSE-react-bancos.txt. As marcas pertencem aos respectivos titulares.

BankLogo utiliza iniciais quando o arquivo não existe ou falha. Os arquivos SVG são carregados em img, sem inserção de HTML externo.
