# Contrato visual NossaGrana

Fonte: imagem fornecida pelo usuário. A área desktop da referência é a aplicação; o telefone e as miniaturas são demonstrações das outras telas, não elementos a inserir no dashboard.

Desktop: sidebar de 210 px; header de 70 px; conteúdo com margem de 28 px; sete indicadores em colunas iguais. Linha de gráficos e listas com proporção 1.25 / 1.25 / 1. Painéis com bordas finas, radius 8 px e gradiente azul-petróleo discreto. Fonte Barlow, condensação e pesos próximos à referência; ícones Lucide de traço fino. Tokens centralizados em apps/web/src/styles/tokens.css.

Mobile até 700 px: sidebar/header desktop ocultos, saudação compacta, saldo, quatro atalhos, gráfico compacto e vencimentos; navegação inferior fixa. Tablet usa sidebar compacta e indicadores em grade sem cortar conteúdo. Tema claro com tokens próprios.

Dados demonstrativos serão substituídos por consultas autenticadas à API; valores financeiros são centavos inteiros.
